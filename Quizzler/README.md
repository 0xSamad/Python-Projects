# Quizzler

A True/False trivia quiz built with Python and Tkinter. Answer randomly generated questions, get instant feedback, and track your score as you play.

![Demo](demo/demo.gif)

## How It Works

1. The app fetches 10 random True/False questions from the Open Trivia Database API.
2. Read each question displayed on the screen.
3. Click the True or False button to submit your answer.
4. The screen turns green for a correct answer and red for an incorrect one.
5. After all questions are answered, your final score is displayed.

## Tech Used

- Python
- `tkinter`
- `requests`
- Open Trivia Database API

## Run It Locally

```bash
pip install requests
python main.py ```
